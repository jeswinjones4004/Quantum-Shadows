# Launch Roadmap

## Phase 1: MVP (Months 1-3)
*   **Goal**: Functional Vulnerability Scanner & Basic Migration Docs.
*   **Deliverables**:
    *   CLI Tool (`npx quantum-shadows scan`).
    *   Basic Web Dashboard with GitHub login.
    *   Support for detecting JS/TS crypto libraries (Node `crypto`, `ethers.js`).
    *   Integration verification with `liboqs-wasm`.

## Phase 2: Developer Beta (Months 4-6)
*   **Goal**: "One-Click" Remediation & Platform Expansion.
*   **Deliverables**:
    *   Automated PR generation (Bot that opens Pull Requests with fixes).
    *   Python and Go language support for scanner.
    *   Vercel Integration for auto-deploy.
    *   Partnership outreach (security audit firms).

## Phase 3: Ecosystem Scale (Month 7+)
*   **Goal**: Enterprise & Gov/NGO Onboarding.
*   **Deliverables**:
    *   On-premise self-hosted version for Governments (Air-gapped support).
    *   API Gateway for legacy apps (drag-and-drop proxy).
    *   Certifications (ISO compliance helper).
    *   Collaboration with CERT-In and global cyber-defense agencies.
